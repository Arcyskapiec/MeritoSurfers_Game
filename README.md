## Sposób uruchomienia
Dla uruchumienia backend-u musisz mieć NodeJS

1. Przejdź do folderu projekt/ i napisz do terminalu z prawami administratora poniższą komendę:
```
node ./backend/start.js
```
2. W przeglądarce napisz URL http://localhost:80/
